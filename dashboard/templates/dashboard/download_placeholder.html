Set up your Barathrum box

Two steps: flash the SD card, then run one install command on the box.

1. Flash the SD card

Download a stock Armbian image for the Orange Pi One from armbian.com/orange-pi-one, then flash it to your SD card using Balena Etcher. Both are official, external sites — Barathrum doesn't host these files.

2. Boot the box and run the install command

Boot the Orange Pi One from the flashed SD card, SSH into it, then download, verify, and run the install script — do not pipe it straight into sudo bash without verifying it first:

curl -fsSLO https://github.com/benzgarcel122-crypto/barathrum-box-agent/releases/latest/download/install.sh curl -fsSLO https://github.com/benzgarcel122-crypto/barathrum-box-agent/releases/latest/download/install.sh.sha256 sha256sum -c install.sh.sha256 && sudo bash install.sh

The middle line downloads a published checksum for the script above; sha256sum -c verifies the downloaded install.sh matches it before && lets it run — if the check fails, nothing executes.
